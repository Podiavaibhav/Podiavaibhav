## 🚀 Featured Projects

### 1. YOLO Annotation QA Pipeline
**Python | PyTorch | YOLOv8 | OpenCV**

- Engineered an end-to-end deep learning pipeline for automated object detection annotation auditing and dataset cleaning.
- Implemented synthetic annotation noise injection, model disagreement detection, and automated dataset correction.
- Recovered **53.6% of mAP50 performance degradation** caused by synthetic annotation noise.
- Achieved 71.8–82.9% detection recall across multiple annotation error categories.

### 2. E-commerce Analytics Warehouse
**PostgreSQL | Python | SQL | Data Engineering**

- Built a star-schema data warehouse containing 445K+ sales records and 60K customers.
- Developed advanced SQL analytics using CTEs, window functions, and aggregations.
- Implemented indexing strategies and materialized views.
- Achieved up to **186.8× query performance improvement** through optimization and benchmarking.

### 3. Reinforcement Learning Experiment Framework
**Python | Q-Learning | NumPy | Matplotlib**

- Implemented tabular Q-learning with a custom stochastic MDP generator.
- Evaluated epsilon-greedy exploration across configurable state-action spaces.
- Visualized learning curves and reward trajectories to analyze agent performance.

### 4. AI-Assisted Artist Portfolio
**Next.js | React | Supabase | GSAP**

- Designed and developed a full-stack artist portfolio platform.
- Implemented Google and GitHub OAuth authentication.
- Integrated Supabase and GSAP animations for a responsive interactive experience.
- Developed search indexing and user-centric application workflows.
